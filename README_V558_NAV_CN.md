# AGV Digital Twin v5.5.8 — 顶部功能栏优化版

## 本次升级

- 基于 v5.5.7.2 epoch30 已验收版，**仅优化顶部导航布局**，不重写 3DGS 加载、Ackermann 驾驶、路径绘制、经纬度计算、控制点配准。
- 顶部功能栏分成 4 组：场景导航、视图工具、模型与仿真、地图与应用；全部保留原按钮 `id` 与事件处理器。
- 桌面端按空间自动换行；手机窄屏默认显示主要导航，点击“更多工具”展开其他功能。
- 右侧弹窗位置会跟随导航栏高度调整；圆形小地图同样下移，避免与导航栏重叠。
- `config/ui_toolbar.json` 可编辑分组标题、按钮显示文案及主题主色（不改功能 ID）。

## 重要：用户提供的 5 份配置

本包原样保存到 `config/`：

1. `ackermann_placement_epoch30_20261015.json`
2. `ackermann_placement_park2_rear_20261019.json`
3. `epoch30_georeference.json`
4. `epoch30_viewer_mesh_registration_v5571.json`
5. `scenes.json`

本版不会自动把历史配准 JSON 认定为真实三维测量。用户此前控制点的 Viewer Z 是固定参考面，Mesh Z 也是人为统一的值，因此原“配准通过”仅证明所输入的点在程序门槛内一致，**不能称为实测三维精度或 GNSS 定位**。

## 启动方法（完整包）

1. 把压缩包解压至独立文件夹；不要覆盖已验收的旧工程。
2. 双击 `start_agv_v55_8_local.bat`，保持终端窗口运行。
3. 打开 `http://127.0.0.1:8104/agv-test.html?v=5.5.8`。
4. 查看顶部四组菜单及功能，窄屏检查“更多工具”。
5. 模型加载后查看左下角模型身份证明：必须匹配原始 epoch30 SPZ；经纬度只是配准后的模拟值。

## 启动方法（轻量补丁）

把更新包中的 `agv-test.html`、`config/` 中 6 个 JSON、`start_agv_v55_8_local.bat` 和 `tools/serve_epoch30_v558.py` 合并到 **v5.5.7.2 完整本地工程根目录**，不要丢掉原来的 `models/`、`assets/`、`src/`。更新包不含大模型。
