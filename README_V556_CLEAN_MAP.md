# v5.5.6：清晰导航地图版（本地实验）

## 改动原因
v5.5.5 的 Spark 离屏俯视未在用户浏览器成功，回退到少量高斯点的 5×5 像素方块投影，导致噪点和黑洞。v5.5.6 不再以这种投影作为 park2 默认底图。

## 新版地图
- 右上角圆形小地图、点击放大、路点新增/拖动/删除、滚轮缩放、JSON 保存/导出功能保留。
- park2 使用从上传的真实 `park2_splat.ply` 的全部 918,596 个高斯中心提取的二维**重建覆盖结构图**（而不是 AI 编造的航拍图）。
- 浅灰表示当前模型的 XY 重建覆盖，青绿色轮廓是相对高处的几何数据聚集位置。两者都**不代表“安全通行区”或精确建筑边界**。
- 车辆、相机、P1/P2 路点和轨迹作为独立清晰图层叠加，继续使用原 Viewer 世界坐标。
- 其他 3DGS 场景若无预生成结构图，优先尝试 Spark 正交视图，失败时改用连续几何密度底图，而不是稀疏彩色小方块。

## 安装
1. 复制已经正常运行的 v5.5.5 本地工程到新文件夹，避免覆盖稳定版。
2. 将更新包里的 `agv-test.html` 和 `assets/minimap/` 原样复制过去，保持相对路径；不要把图片单独放到根目录。
3. 双击 `start_agv_v55_6_local.bat`，打开 `http://127.0.0.1:8101/agv-test.html?v=5.5.6`。
4. 确认在 park2 中，大地图状态行显示“park2 高斯几何结构图（非航拍影像）”，而不再是“高斯点俯视投影”。
5. 在地图上设置 P1、P2、P3，核对三维场景中位置一致，并测试自动巡航。`index.html` 及 GitHub 仓库本次不变。

## 数据与风险边界
- 当前结构图来自原模型点位的平面密度与高度分布；缺失顶视图、遮挡和不完整重建仍然存在。它**不等于**真实照片、测绘图、高清航拍图、道路可通行栅格或真实 AGV 的导航地图。
- 几何密度轮廓作为定位和轨迹编辑参考。要获得真正高清真实俯视影像，需额外获取覆盖顶面的航拍/高处采集素材或米制 LiDAR 地面/占据栅格，并和 Viewer 使用控制点做配准。
- 已知的 2.26m 单段距离可以用于初步统一尺度；不代表完成了全局配准与精度检验。
- 切换其他模型，当前图不会错误复用：将检查场景名称、点数量以及边界中心。

## 验收
- park2 小地图清晰连续，不再出现稀疏点状噪声。
- 彩色路线与标定点在小地图、大地图及主三维场景中持续可见。
- 真实场景和地图的 AGV 位置、车头朝向及路线点同步。
- 既有运动学、巡航、车辆尺寸、模型替换与移动端控制不受影响（需在用户真实浏览器回归确认）。
