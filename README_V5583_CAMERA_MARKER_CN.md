# v5.5.8.3：AGV 小地图相机箭头修正（本地版）

## 修复内容
- 橙红色箭头：虚拟 Ackermann 车辆的位置与车头朝向，始终显示。
- 旧版白色箭头：Viewer 摄像机位置/朝向。开启跟随相机时，它会随车辆移动，看起来像第二辆车。
- 此版默认隐藏摄像机箭头。大地图底部新增「显示相机方向（调试）」复选框；打开后以蓝色箭头显示摄像机朝向。该偏好写入浏览器本地 localStorage。
- 保留 v5.5.8.2 的可拖动圆形小地图、四组下拉菜单、驾驶、经纬度配准和轨迹编辑。未修改车辆运动学与地理参考数值。

## 本地启动
1. 解压完整工程，不要覆盖原 v5.5.8.2。
2. 双击 start_agv_v55_8_3_local.bat。
3. 打开 http://127.0.0.1:8107/agv-test.html?v=5.5.8.3&scene=epoch30_20261015
4. 查看小地图：默认只显示橙红色车辆方向标；需要调试摄影机时，点击圆形地图放大，在底部勾选「显示相机方向（调试）」。
5. 仍显示双箭头时，检查是否实际运行在 8107 端口，并强制刷新浏览器。

## 注意
- 场景坐标从 Mesh 地理参考推算，不是实时 GNSS 或 RTK 定位。
- 此修改只涉及地图标记绘制，不修改车头 yaw、第三人称相机跟随或轨迹数据。
- 不会更新 GitHub。
