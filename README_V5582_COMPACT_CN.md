# AGV Digital Twin v5.5.8.2 — 顶栏单排和可拖动小地图（本地版）

## 启动

1. 直接解压完整工程（不要覆盖已验收的旧版）。
2. 双击 `start_agv_v55_8_2_local.bat`；若 8106 端口占用，先关闭占用它的旧窗口。
3. 打开 `http://127.0.0.1:8106/agv-test.html?v=5.5.8.2&scene=epoch30_20261015`。
4. 终端会在启动前核验 epoch_30 SPZ 的 29,254,747 字节与 SHA-256 指纹。

## 新版交互

- **顶部一排**：四个一级入口固定排列在中国铁建标题右侧，不再占据独立的第二、三排。
- **折叠**：点击每组右侧的 `▸` 展开下拉功能，再点击 `▾` 收起。为避免下拉框互相覆盖，一次只展开一组；点击空白区域或功能按钮会自动收起。
- **记忆状态**：默认全部收起。浏览器的展开状态使用版本独立的 localStorage 键保存。
- **圆形小地图**：按住鼠标左键拖动位置，触控屏长按拖动；只点击不移动会打开原有全屏路线编辑地图。拖动后的位置保存在当前浏览器，窗口改变大小时自动约束在可见区域。右键小地图（或聚焦后按 Home）可恢复自动停靠位置。
- **地图路线编辑**：在大地图内继续放置、拖动和删除轨迹点，功能和 v5.5.8.1 一致。

## 不变的功能与限制

- 默认加载 `models/2026-10-15_10-31-41_3DGS_epoch_30.spz`；没有自动切换其他场景的回退路径。
- 保存已上传的 `config` 配置文件，不修改 Ackermann 运动学、路线坐标及地理转换计算。
- 经纬度属于依据 Mesh 地理参考及用户历史控制点方案推算的虚拟位置，**不是 GNSS/RTK 实测**。
- 当前取点工具仍为固定参考地面交点，不是 3DGS 表面真实 Z 拾取。
- 只有旧端口不同（8105→8106），浏览器不同端口的 localStorage 不会自动同步。跨版本请使用界面导出/导入配置。
- 不更新 GitHub Pages。

## 配置

`config/ui_toolbar.json` 设置四组标题、显示文案及默认折叠状态；相关场景、地理与车辆 JSON 仍保留在 `config/` 中。

## 测试项

1. 开始四个一级入口应在中国铁建标题右边同一水平行；仅一个下拉菜单展开。
2. 点击四组所有原功能按钮，验证轨道/漫游、驾驶、地理参考、全屏、模型切换以及俯视大地图。
3. 点击小地图应放大，拖动小地图只应移动位置、不触发放大。
4. 拖动后刷新位置保留；右键（或 Home）恢复自动停靠。
5. 在驾驶面板打开/关闭时检查小地图默认不遮挡面板。

## 验收分级

- 结构 / JS 语法 / 单元和离屏浏览器交互：自动检测。
- 用户 Windows 本机加载真实 epoch_30 和完整驾驶交互：仍需实际验收。
