# AGV Digital Twin v5.5.4 — Ackermann Driving Simulation

## 本次实现

在 v5.5.3 CAD 实尺摆放和 park2 PLY 场景上进行**增量开发**。稳定的 `index.html`（v5.4 公网首页）原封未改。只有 `agv-test.html` 是开发版本。

- 独立 `驾驶 v5.5.4` 面板，W/S 前进倒车、A/D 转向、空格紧急停车。
- 标定沿用：Viewer -Z Up；Yaw=0° 时车头 +X；左转=正 Yaw。
- CAD 轴距 0.802603m，前轮轮距 0.688m，车轮半径约 0.202m。
- 车辆按米制自行车运动学积分；前两轮按 Ackermann 内外轮角差转向、四个车轮按行驶距离转动。
- 最大模拟转角 25°（不是机械限位声明），速度可调 0.05–1.00 m/s，默认 0.30m/s。
- 限加速度 0.5m/s²，制动减速度 0.8m/s²，60Hz 固定物理步长。
- 绿色实际模拟行驶轨迹，行驶里程、车轮角度、速度、车位信息。
- 可选第三人称跟随相机。点击“退出驾驶”或关闭面板，立即停下。
- 自动巡航初版：从 AGV 路线编辑器读取至少三个不同的道路路点；Pure Pursuit 曲线跟踪、偏离检测、终点减速停车。默认没有演示路线，不会把 P1-P2 距离校准标记冒充安全路线。
- 仿真位姿默认**不覆盖**之前的标定配置；只有点击“明确保存当前位置”才保存位置。退出后点“恢复初始车位”可回到标定位置。
- Ackermann CAD 面板新增“导入小车配置 JSON”功能。可导入之前导出的符合本场景 ID 的真实配置。
- 模型选择窗口增加“关闭”及 Esc 关闭。

## 使用方式（推荐轻量包）

1. **不要覆盖** v5.5.3。先把整个 v5.5.3 文件夹复制为 `3DGS_Web_Viewer_v5_5_4_ACKERMANN_DRIVE`。
2. 将 `3DGS_Web_Viewer_v5_5_4_UPDATE_ONLY.zip` 解压后覆盖到复制的新文件夹。
3. 检查至少有：`models/park2_splat.ply` 和 `assets/ackermann/ackermann_urdf_meters.glb`。它们无需重新上传或再次转换。
4. 双击 `start_agv_v55_4_local.bat`，浏览器应打开 `http://127.0.0.1:8099/agv-test.html?v=5.5.4`。
5. park2 加载后应恢复小车位置 X 0.10827, Y -0.34869, GroundZ 0.006, Scale 0.0738821（如浏览器有更新过的本地草稿，以本地草稿为先）。
6. 点击顶部 **驾驶 v5.5.4**，按 **进入手动驾驶**，先短按 W，再 A/D，观察车头、轨迹。
7. 按 **空格** 立即停车。**恢复初始车位**不会写回标定数据。
8. 需要连续看车辆行驶时可勾选“第三人称跟随相机”。

## 自动巡航（独立演示路线）

在 AGV 面板中布置至少 3 个位于空旷地面的**新**路点，从第一个点到第三个点尽可能平滑，避免建筑物和花坛。按 Esc 停止布点。在驾驶面板中点击“启动自动巡航”并确认；小车从路线起点面向下一路点，按 Pure Pursuit 跟随并在终点减速。

注意：路线没有三维可行驶表面约束、路径规划或碰撞检测。前期画出的 P1/P2 2.26m 尺度标定线**不是**可安全通行的路径。纯视觉演示，不向 ROS 发布运动控制指令。

## 标定

预置了用户 2026-10-19 已确认的视觉接地位置与单段 2.26m 实测比例：

```text
config/ackermann_placement_park2_rear_20261019.json
X 0.10827
Y -0.34869
GroundZ 0.006
Yaw 0 deg
viewerUnitsPerMeter 0.0738821
```

如果你有更精确的 `ackermann_placement_park2_rear_20261019.json`，请把那份放入 `config/` 覆盖预置；但注意同一个 `http://127.0.0.1:8099` 源的浏览器 localStorage 可能优先于该文件。

此校准只有单段真实距离基准和视觉验收，**不等于完整 3DGS 米制精度验证或 ROS map→Viewer 的 Sim(3) 配准**。运动速度在该尺度约定下计算，不承诺实车定位精度。

## 局域网手机查看

双击 `start_agv_v55_4_lan.bat`，确保与已有8099服务不冲突，手机访问 `http://电脑局域网IP:8099/agv-test.html?v=5.5.4`。手机可以观看自动巡航，**手动键盘驾驶目前主要为桌面端设计**，此版未添加单独的手机驾驶摇杆；原有手机场景漫游摇杆仍保留。

## 验收及问题定位

- 核对地址必须为 `8099`、`v=5.5.4`，切勿误点旧 `8098` 入口。
- 进入场景后车辆应恢复原已验证位置及尺寸，不用重新配准。
- W: 沿真实车头 +X 方向前进，S: 相反。
- A+W: 车头向车辆左侧转，左前轮内角应略大于右前轮角。
- D+W: 相反，右前轮内角应更大。
- 松开 W，速度平滑回零；按空格立即停止。
- 退出驾驶后，相机 WASD 漫游仍正常。
- 切换到会议室模型后不能继承 park2 的车位、轨迹、尺度。
- 浏览器按 F12→Console 查看错误；如主程序仍然停留 0%，请截图控制台和 CMD HTTP 日志。

## 技术范围

本次是**局部运动学仿真**，不是动力学仿真：没有悬挂、轮胎侧偏、实车执行器、真实碰撞、Gazebo/Unreal/ROS 控制或机器人定位。GLB 视觉模型采用详细 SolidWorks URDF，几何未改。相关数学检查在 `tests/test_ackermann_kinematics.cjs`，运行 `node tests/test_ackermann_kinematics.cjs`。
